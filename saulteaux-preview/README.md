# Saulteaux GBA art preview build

This is an artwork-only checkpoint. It is intentionally not the learning-game implementation yet.

Included in the preview:

- One corrected Turtle Island master map with one head and four flippers.
- Turquoise/teal ocean with an eight-frame flowing wave overlay.
- Overview camera plus seven camera destinations that zoom into exact crops of the same master map.
- Makwa walk sheet, eagle prompt portraits, flying eagle sheet, and the four current 20-object atlases (80 illustrated references so far).
- Offline PWA shell with no CDN or runtime network dependency.

Open `index.html` from a local static server to allow the service worker to cache the preview. The asset locker is only a visual gallery; it does not yet contain the 300-word learning flow.
